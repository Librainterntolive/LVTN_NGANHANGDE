# Du lieu luu tru, khong dung de import

Thu muc nay chua cac file phat trien cu, khong co `source_title`, `source_url` va `source_reference` cho tung cau hoi. Cac file nay khong phai du lieu nghiem thu va khong duoc dung de demo/bao cao.

He thong hien tai tu choi cac file nay khi import. Chi dung file xuat tu mau import moi va bo sung day du nguon tai lieu co the kiem chung cho tung dong cau hoi.

Du lieu minh chung hien tai duoc quan ly tai `database/seed-go-official-basics.sql`; xem `scripts/HUONG-DAN-KIEM-TRA-DU-LIEU.md` truoc khi nghiem thu.
